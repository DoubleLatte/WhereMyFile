# WhereMyFile 웹 버전 — 브라우저에서 쓰는 중복 파일 찾기

폴더나 파일을 고르면 내용이 완전히 똑같은 파일을 찾아 묶어 보여 주는 웹 프로그램입니다.
1주차에 만든 C++ 콘솔 프로그램(WhereMyFile)의 비교 방식을 JavaScript로 그대로 옮겼습니다.
파일은 서버로 올라가지 않고, 이 브라우저 안에서만 읽습니다.

## 사용 방법

1. 폴더나 파일을 페이지 어디에든 끌어다 놓습니다. (또는 "폴더 고르기", "파일 고르기")
2. 놓으면 바로 검사가 시작됩니다. 고르기 버튼을 썼다면 "검사 시작"을 누릅니다.
3. 오른쪽에 똑같은 파일 묶음과 확보할 수 있는 용량이 나옵니다.
4. 묶음을 펼쳐 남길 파일을 바꾸거나, "정리 목록 저장"으로 사본 목록을 txt로 받습니다.

브라우저는 보안상 내 컴퓨터의 파일을 옮기거나 지울 수 없어서, 실제 정리는 PC용 WhereMyFile로 합니다.

## 비교 방식 (C++판과 같음)

1. 크기가 같은 파일만 후보로 묶습니다. 크기가 다르면 읽지 않습니다.
2. 후보를 청크(기본 1 MB)씩 읽어 바이트 단위로 비교하고, 한 바이트라도 다르면 바로 멈춥니다.
3. 끝까지 같으면 같은 묶음입니다. 묶음은 낭비 용량이 큰 순서로 보여 줍니다.

해시가 아니라 바이트를 직접 비교하므로 "같다"는 결과는 실제로 같은 파일입니다.

## 설정

- 남길 파일 기준: 이름이 가장 짧은 파일(기본) / 가장 오래된 / 가장 최근 / 경로 순서
- 청크(버퍼) 크기: 16 KB ~ 64 MB
- 하위 폴더까지 검사: 켜기 / 끄기
- 테마: 그레이&골드 / 화이트&골드 (상단 바)

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 (첫 화면, 검사 도구, 비교 방식, 질문) |
| `analyzer.js` | 분석 로직: 크기 분류, 청크 바이트 비교, 정렬, 남길 파일 기준 |
| `app.js` | 화면 처리: 파일 고르기, 끌어다 놓기, 검사, 결과 표시, 목록 저장, 테마 |
| `app.css` | 이 페이지의 스타일 |
| `assets/` | 디자인 키트(레이아웃, 버튼, 모션) |
| `test/analyzer.test.js` | 분석 로직 자동 테스트 |

## 실행

- 서버 없이 정적 파일만으로 동작합니다. GitHub Pages에 그대로 올리면 됩니다.
- `index.html`을 더블클릭해 열면 검사 기능은 동작하지만, 디자인 키트 스크립트가 막혀 모션과 메뉴 펼침이 빠집니다.
  로컬에서 확인할 때는 `npx serve .` 같은 간단한 서버로 여세요.

## 테스트

```
node test/analyzer.test.js [C++판과 비교할 폴더]
```

1주차 테스트 표의 경우(이름만 다름, 크기 같고 내용 다름, 빈 파일, 마지막 1바이트 차이, 청크 3종,
남길 파일 기준, 하위 폴더 끄기, 숨김 이름 제외)를 확인합니다. 폴더를 주면 C++판과 숫자를 비교할 수 있습니다.
